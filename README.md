# Wandrly--web

Wandrly – Full Stack Travel Listing Platform

Wandrly is my first full-stack web application, built as part of my learning journey in web development.  
It is a travel & stay listing platform where users can explore destinations, view listings, and interact with a dynamic, database-driven application.

 This project is actively evolving — I am currently improving responsiveness across devices and refining the UI for smaller screens.

Live Demo
🔗 https://wandrly.onrender.com  

Features:
- Browse travel & stay listings
- User authentication (Sign up / Log in / Log out)
- Create, edit, and delete listings (authorized users)
- Reviews system
- Responsive layout (work in progress)
- RESTful routing & MVC architecture

Tech Stackz:
Frontend
- HTML
- CSS
- Bootstrap
- EJS (Embedded JavaScript Templates)

Backend
- Node.js
- Express.js

Database
- MongoDB
- Mongoose

Other Tools
- Passport.js (Authentication)
- Express-session
- Method-override
- Cloud deployment (Render)

 Project Structure:
 
 Authentication & Authorization:
- User login and signup functionality
- Only authenticated users can create listings
- Only listing owners can edit or delete their listings
- Session-based authentication

Responsiveness Status:
- Desktop layout:  Implemented
- Tablet & Mobile layout: In progress  
I am actively working on improving mobile responsiveness and learning real-world responsive debugging techniques.

 Learning Outcomes:
- Connecting frontend with backend using Express
- Working with MongoDB and Mongoose schemas
- Implementing authentication & authorization
- Structuring projects using MVC architecture
- Debugging layout and deployment issues
- Understanding responsive design challenges
